# 展示会名刺 / Boothcard — Support Site

Static support site and privacy policy for the iOS app **展示会名刺 (Boothcard)**, served via GitHub Pages.

| | 日本語 | English |
|---|---|---|
| Support | <https://hibinokou-spec.github.io/tenjikai-meishi-support/> | <https://hibinokou-spec.github.io/tenjikai-meishi-support/en/> |
| Privacy Policy | <https://hibinokou-spec.github.io/tenjikai-meishi-support/privacy/> | <https://hibinokou-spec.github.io/tenjikai-meishi-support/en/privacy/> |

App Store: <https://apps.apple.com/app/id6758286019>

No build step — plain HTML/CSS. All pages share `assets/style.css`.

```
index.html            日本語 サポート
privacy/index.html    日本語 プライバシーポリシー
en/index.html         English support
en/privacy/index.html English privacy policy
privacy.html          旧URL。/privacy/ へのリダイレクトのみ（ASC 登録済みURL保護のため残置）
assets/style.css      共通スタイル
```

Content reflects app version 1.2.0. Prices are deliberately not stated on the site
(they differ by storefront).
